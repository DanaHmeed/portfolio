# Visual direction — revised

- Palette: deep neutral `#0D0E10`, raised neutral `#15171A`, high-contrast ink `#F1F2EE`, restrained acid-lime `#C8FF45`; independently tuned warm light theme.
- Typography: Manrope for English, Noto Sans Arabic for Arabic, IBM Plex Mono for technical metadata. No display serif.
- Spatial language: modern asymmetric grid with compact section rhythm and a technical system canvas.
- Component language: full-width records, fine rules, square edges, technical labels, no generic cards.
- Illustration: geometric-flat system views built in HTML/CSS, using the same rule weight and palette.
- Icons: 1.5px sharp outlined SVGs using `currentColor`.
- Motion: 2/3, Energetic-but-restrained personality. Framer Motion reveals, an SVG signal trace, project lift, navigation feedback, and theme transitions.
- Smooth scroll: Tier 3 Lenis on pointer devices, with native fallback for reduced motion and touch.
- Internationalization: centralized EN/AR dictionary, persisted preference, document-level `lang`, `dir`, and RTL-aware logical properties.
- Theme: dark by default; persisted light/dark preference with independent semantic tokens.
- Design variance: 6/10. Visual density: 5/10.
